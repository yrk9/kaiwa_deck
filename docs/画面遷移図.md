# 画面遷移図

作るページと、ページ間の移動の決まり。各ページが使うAPIは [API設計.md](./API設計.md) を参照。

## ページ一覧

| ページ | 役割 | 作る時期 |
|---|---|---|
| `/` | LP(コンセプトの説明と「はじめる」。押すと匿名ログイン) | M8 |
| `/decks` | 自分のデッキ一覧、新規作成(「公式お題入りで作る」あり) | M8 |
| `/decks/[id]` | デッキ内のお題の一覧・追加・削除、自分のお題の作成、「部屋を作る」「ひとりで引く」 | M8(部屋のボタンはM9) |
| `/room/new` | 部屋を作る(デッキを選び直せる、部屋名を入れる) | M9 |
| `/room/[id]` | 招待リンクの受け口 兼 ドロー画面 | M9(ひとり)、M10(リアルタイム) |

## 遷移図

```
/ (LP)
  └─ 「はじめる」(匿名ログイン) ──▶ /decks
                                     ├─ 「公式お題入りで作る」 ──▶ /decks/[id]
                                     └─ デッキを選ぶ ──▶ /decks/[id]
                                                           ├─ 「部屋を作る」 ──▶ /room/new?deck=[id]
                                                           └─ 「ひとりで引く」(部屋を自動で作る) ──▶ /room/[id]

/room/new ──作成──▶ /room/[id]

招待リンク(外部) ──▶ /room/[id] (未参加なら「参加する」。参加後はドロー画面)

/room/[id] ──退出 / 解散 / 部屋が消えた──▶ /decks
```

## `/room/[id]`の状態

1つのページが、状態によって表示を切り替える。

- 読み込み中
- 未参加: ルーム名と参加者を見せて、「参加する」ボタン(参加前でも見られるAPIを使う)
- 参加済み: 引く・引いたお題・残り枚数・参加者・リセット・退出・招待リンクのコピー
- 満員(409): 参加できないことを知らせる
- ルームが無い(404): 終了したことを知らせて、`/decks`へ

## 作らないもの

- `/play`(モード選択): 「ひとりで引く」は、1人だけのルームを自動で作ることで足りるため
- 自分が参加中のルームの一覧(`GET /room/`): URLを共有して使う前提のため。必要になったら追加する
